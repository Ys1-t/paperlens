🤖 AI 助手（对话 API 可与翻译分开）

      

        阅读器右侧「科研助手」走独立的对话接口，可以与翻译使用不同的 API / 模型。
        例如：翻译用便宜视觉模型，助手用更强的推理模型。
      

      
      
      
    
        
  1. 在上方 模型服务 → Provider Profile 里 新建 一套（例如命名为「助手-强模型」），填好 Base URL、API Key、模型，点保存。
    2. 
        
  2. 翻译仍用「设为当前」的那一套 Profile。
    3. 
        
  3. 在本下拉框选择刚才那套 Profile（不要选「与翻译当前 Profile 相同」）。
    4. 
        
  4. 点页面底部 保存。打开阅读器后，助手标题下会显示「对话：xxx · 模型名」。
    5. 
      

      

        默认「与翻译当前 Profile 相同」：不另配时，助手与翻译共用同一 Key/模型。
        对话请求不写入翻译缓存；Key 仅保存在本机扩展存储。
      

    


    

      
📓 Obsidian 本地库（科研笔记）

      

        推荐：直接写入你的 Obsidian 库文件夹（无需插件、无需 API）。
        文件会出现在 库/PaperLens/论文标题.md，用 Obsidian 打开即可阅读与继续编辑。
      

      
      
      

        
        
        
      

      
    
        
  1. 勾选「启用写入 Obsidian」，点 选择库文件夹，选中你的 Obsidian vault 根目录（里面有 .obsidian 的那一层）。
    2. 
        
  2. 点页面底部 保存。
    3. 
        
  3. 阅读器「科研助手 → 笔记」点 Obsidian，笔记会写入 PaperLens/论文名.md。
    4. 
        
  4. 回到 Obsidian 即可看到新文件（若未出现，在文件列表刷新或切换一下文件夹）。
    5. 
      

      

        高级：Local REST API（可选，一般不必）
        
仅在无法使用「选择文件夹」时再配。请勿把翻译模型的 Base URL 填到这里。

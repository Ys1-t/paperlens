开始阅读论文

左侧保留 PDF 原版，右侧实时生成中文译文与 LaTeX 公式。拖入文件，或粘贴 PDF 链接即可开始。

  • 同时读多篇：再开一个阅读器标签（插件图标 → 打开），不要在同一页硬换文件。
  • 译文太长：工具栏点「滚动联动」→「独立滚动」，或按住 Alt 临时停住原文。
  • AI 助手可在设置里单独指定更强模型 Profile，与翻译 API 分开。

阅读快捷键

  • J / K（或 PageDown / PageUp）下一页 / 上一页
  • O 打开 / 关闭目录侧边栏
  • A 打开 / 关闭科研助手
  • Ctrl+K 搜索科研助手技能
  • S 框选提问（在左侧 PDF 拖矩形，Esc 取消）
  • Ctrl+Shift+L 切换滚动联动
  • Alt 按住：临时解除联动（原文停住）
  • 双击译文：定位左侧原文对应位置
  • 点击「第 N 页」标题：左右栏同步跳到该页
  • 划词：即时翻译 / 问 AI
  • ? 打开本帮助
  • Esc 关闭帮助 / 目录 / 助手面板

# PaperLens 1.1：AI 助手与视觉翻译 40 项迭代

更新日期：2026-07-30

本轮不是把旧 Page IR 管线重新拼回产品，而是在 1.0 的“整页视觉翻译唯一主路径”上增加两类确定性能力：

1. AI 助手采用“本地证据检索 → 模型推理 → 引用审计”的证据优先工作流。
2. 翻译采用“页面图像负责版面 + PDF 原生文本负责覆盖提示 + 本地多维质量门”的双信号工作流。

以下每一项都对应代码、界面或自动化测试，不把纯讨论计作迭代。

## A. 本地论文证据引擎

- [x] 01. 中英文混合 tokenizer：同时处理汉字词组、英文单词、缩写和数字。
- [x] 02. 英文轻量词形归一：learned / learning / policies 等查询更容易命中。
- [x] 03. 中文二元与三元词组：不依赖浏览器分词器，也能检索“复杂度分析”等词。
- [x] 04. 页内分块：长页面按段落与句子边界切块，并保留有限重叠。
- [x] 05. BM25 风格相关度：替换旧的“第一个精确子串命中”。
- [x] 06. 精确短语与标题加权：章节标题和完整术语优先。
- [x] 07. 当前页轻量加权：跟进“这页 / 这里”时更符合阅读现场，但不会压过强相关页。
- [x] 08. 原文 / 译文 provenance：每条证据明确标记来自 PDF 原文还是译文。
- [x] 09. 页级去重：同一页多个高分块不会挤占全部结果。
- [x] 10. 邻页扩展：跨页算法、图注和实验描述可带入相邻页，同时标记 neighbor 来源。
- [x] 11. 紧凑 evidence pack：发送模型前生成可审计的证据包，不增加额外 API 轮次。

## B. 科研 Agent

- [x] 12. 深读首轮自动检索：用户问题直接驱动本地 evidence pack。
- [x] 13. 新增 retrieve_evidence 工具：模型需要补证时可再次做相关度检索。
- [x] 14. 新增 get_page_range 工具：连续读取最多 6 页，适合跨页算法与实验。
- [x] 15. search_paper 升级：返回相关度、页码与原文 / 译文类型。
- [x] 16. 工具协议兼容 JSON tool object：部分兼容模型不严格输出 CALL 行时仍能执行。
- [x] 17. 页码合法性审计：识别超过 PDF 总页数的幻觉引用。
- [x] 18. 证据覆盖审计：识别模型引用了从未检索或读取的页。
- [x] 19. Agent system context 限定证据边界：页列表摘要不能被扩写成实验数字。
- [x] 20. 长历史本地压缩：保留旧对话要点和涉及页码，最近对话保持原文，不增加模型调用。
- [x] 21. 快问模式自动附当前页：不附截图也能感知用户正在阅读的论文页。

## C. 助手用户体验

- [x] 22. 回答下展示“证据已核验 / 引用需核对 / 未标页码”。
- [x] 23. 证据页按钮可点击回到 PDF 对应页。
- [x] 24. 显示“基于原文 / 基于译文 / 原文 + 译文”。
- [x] 25. 历史会话保留 skillId、查阅过程、证据页与引用审计，不再只存纯文本。
- [x] 26. 用户上滚后暂停强制滚底，长回答阅读位置不再被流式输出抢走。
- [x] 27. 增加“回到最新内容”按钮，恢复跟随由用户显式决定。
- [x] 28. 回答操作常态可见，不再完全依赖 hover 才能发现复制 / 笔记 / 重试。
- [x] 29. 科研工作台视觉：纸张色、墨色、玉绿色证据状态与琥珀色警告，降低通用紫色渐变感。
- [x] 30. aria-busy 与可聚焦证据控件：生成状态、证据页和回到底部均可被辅助技术理解。

## D. 视觉翻译质量闭环

- [x] 31. 目标语言覆盖检查：拦截几乎没有中文的异常结果。
- [x] 32. 成段英文残留检查：排除参考文献与代码后检测漏译英文段落。
- [x] 33. LaTeX 定界符检查：检查单美元、双美元、反斜杠括号是否闭合。
- [x] 34. 裸 LaTeX 检查：检测未放入公式定界符的 frac、partial、boldsymbol 等命令。
- [x] 35. 源文覆盖率检查：PDF 原生文本足够长但译文过短时判为漏段。
- [x] 36. 重复段落 / 异常膨胀检查：识别错序、循环和重复标题。
- [x] 37. 译文媒体检查：禁止模型把图片以 Markdown 图片或 img 标签复制到译文栏。
- [x] 38. 双信号视觉请求：图片决定版面，PDF 原生文本只辅助覆盖与小字辨认。
- [x] 39. 按失败原因定向重试：英文、公式、漏段、错序、图片、自言自语分别给出修复指令。
- [x] 40. 质量失败进入智能自动重试；重试绕过坏缓存，成功后清除失败状态。

## 保留且继续验证的产品约束

- 默认阅读模式。
- 译文中的公式继续使用 KaTeX / LaTeX。
- 图片和表格主体留在左侧 PDF，译文栏只保留定位入口及图注 / 表注。
- 双击译文定位原文，双击原文定位译文；单击不触发跳转。
- 多 Provider Profile，可为翻译与 AI 助手分别选模型。

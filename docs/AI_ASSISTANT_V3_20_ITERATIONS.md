# PaperLens 1.2.5：AI 助手与视觉翻译再迭代 20 项

更新日期：2026-07-30

本轮基于 1.1.0 的证据优先科研助手与整页视觉翻译继续收口。每一项均对应实际代码与自动化测试；仅写想法、不改变产品行为的内容不计入迭代。

## A. 可核对的科研助手

- [x] 01. 证据支持度：回答后输出 0–100 的可追溯性指标，并明确它不等于“答案正确率”。
- [x] 02. 可展开证据卡：在回答下展开 E1、E2 等真实检索片段，显示页码、原文/译文来源、章节线索和邻页关系。
- [x] 03. 一键回页核对：证据摘要和每条证据均提供原生按钮跳到对应 PDF 页。
- [x] 04. 跨轮证据记忆：追问时复用上一轮实际查阅片段，不把助手旧结论冒充论文证据。
- [x] 05. 历史证据持久化：IndexedDB 保存有限条数、有限长度的证据片段与支持度，恢复历史会话后证据卡仍可用。
- [x] 06. 笔记证据溯源：收入科研笔记或自动导读笔记时附带核对页、来源和支持度。
- [x] 07. Markdown 对话导出：新增 MD 下载入口，回答正文后带证据摘要与片段，不嵌入 base64 页图。
- [x] 08. PDF 对话导出：打印版对话附带经过 HTML 转义的证据摘要与片段。
- [x] 09. 技能命令面板：Ctrl+K 搜索全部科研技能，支持按技能名称和用途排序，不需要模型请求。
- [x] 10. 无障碍技能操作：方向键选择、Enter 运行、Escape 关闭、Tab 焦点约束、关闭后焦点恢复，并通过文本而非纯颜色表达状态。

## B. 更稳定的深读 Agent

- [x] 11. 普通取证无阅读副作用：Agent 默认使用只读 get_page，不再用 goto_page 擅自改变用户阅读位置。
- [x] 12. 工具循环去重：同一轮及跨轮去除完全重复的工具调用，防止兼容模型反复 CALL 同一页或同一查询。

## C. 视觉翻译结构质量门

- [x] 13. 拒答与提示注入隔离：页面图片和 PDF 文本提示一律视为不可信论文数据；检测模型拒答并定向重试。
- [x] 14. Markdown 与 LaTeX 结构检查：拒绝未闭合代码围栏、损坏公式定界符和不平衡 LaTeX 花括号。
- [x] 15. Algorithm 结构检查：检测算法页是否保留 algorithm 围栏、独立行号和至少一个嵌套缩进行。
- [x] 16. Figure/Table 结构检查：存在图注或表注时要求定位 token；图片和表格主体仍只留在左侧 PDF。
- [x] 17. PDF 不可变锚点检查：核对引用标记、方程编号、百分比、关键小数、数据集名和缩写，缺失时带具体锚点重试。
- [x] 18. 按原因精修：拒答、算法、图表、围栏、花括号和锚点缺失分别生成不同修复指令，并全部进入智能自动重试。

## D. 速度与清晰度平衡

- [x] 19. 自适应输出预算：普通页保持 4096；PDF 文本较密时才提高到 6144 或 8192，质量重试固定 temperature 0。
- [x] 20. 自适应图像清晰度：普通页保持 1500px，密集页适度升至 1640/1780px；只有质量失败页使用 2050px 高精度整页复核。

## 保留的产品约束

- 默认阅读模式。
- 译文中的公式继续用 LaTeX / KaTeX 渲染。
- 图片与表格主体不复制到译文栏，只保留定位入口及可见图注、表注。
- 原文与译文定位仍由双击触发，普通单击不跳转。
- 多 Provider Profile 保留，可为翻译和 AI 助手分别选择模型。
- 正常页面不增加额外视觉调用；只有本地质量门拒绝的页面才进入高精度复核。
